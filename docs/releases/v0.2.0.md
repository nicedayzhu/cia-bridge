# CIA Bridge v0.2.0

CIA Bridge v0.2.0 adds offline CIA identification while keeping file selection and transfer independent from online title databases.

## Highlights

- Reads embedded TMD and optional SMDH metadata directly from selected CIA files.
- Shows the localized title, icon, publisher, Title ID, version, region, content type, and New Nintendo 3DS requirement when available.
- Reads only bounded file ranges instead of loading an entire CIA into memory.
- Keeps files sendable when metadata is missing, malformed, or unavailable from an Android document provider.
- Adds a responsive details sheet and updated Windows/Android file cards.
- Uses the project's persistent Android release certificate for GitHub releases from v0.2.0 onward.

## Upgrade note

The v0.1.0 preview APK used a development certificate. Uninstall v0.1.0 before installing the v0.2.0 GitHub release. Later officially released versions can update v0.2.0 in place.

CIA Bridge v0.2.0 新增完全离线的 CIA 信息识别：直接读取文件内嵌的 TMD 与可选 SMDH，显示本地化标题、图标、发行商、Title ID、版本、区域、内容类型和 New Nintendo 3DS 要求。解析只读取必要区间，失败不会阻止发送，也不依赖 3dsdb 等在线标题数据库。
