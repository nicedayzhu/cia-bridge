# CIA Bridge v0.1.0

The first public preview of CIA Bridge, a LocalSend-inspired LAN sender for FBI Remote Install on Nintendo 3DS.

## Highlights

- Native Windows x64 portable package with no Java/JRE dependency.
- Android 7.0+ APK with system file picker and foreground transfers.
- Progressive device → file → send workflow shared across both platforms.
- Nintendo OUI discovery where supported, plus safe Android online-device candidates.
- FBI TCP URL push and LAN QR-code install modes.
- Streaming HTTP server with fixed content length, UTF-8 filenames, and range support.
- Automatic/manual device refresh, light/dark themes, responsive layouts, and transfer result states.

## Downloads

- `CIA-Bridge-v0.1.0-Windows-x64.zip`
- `CIA-Bridge-v0.1.0-Android.apk`

The Windows archive must be extracted as a whole. The Android APK is intended for side-loading and is signed with a debug certificate in this preview release.

## Notes

- Keep the computer/phone and 3DS on the same trusted LAN.
- Open `FBI → Remote Install → Receive URLs over the network` before using push mode.
- On modern Android, compare a candidate device with the IP displayed by FBI.
- CIA Bridge does not provide CIA files or download sources.
